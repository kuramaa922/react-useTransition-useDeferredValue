# react-useTransition-useDeferredValue

В проекте реализован следующий функционал: есть инпут для поиска и большой список продуктов в виде строк, сгенерированных с помощью цикла.

Теперь попробуй ввести “123” в строку поиска, удалить “3”, а потом удалить “2”. Если у тебя слабый компьютер, то, возможно, ты сразу заметишь, что при удалении значений из строки поиска сначала вычисляется список отфильтрованных значений, затем обновляется вводимое значение в инпуте. Такой интерфейс не является отзывчивым, так как непосредственные манипуляции пользователя не отображаются сразу в интерфейсе.

Если у тебя достаточно мощный компьютер и ты не заметил вышеописанной проблемы, то перейди в Chrome DevTools во вкладку Performance и выбери в поле CPU значение “6x slowdown”, чтобы искусственно замедлить вычисления:
